# Security Policy

## Supported versions

Only the latest release of Glide Pad receives fixes. Please update to the newest version from [Google Play](https://play.google.com/store/apps/details?id=com.neerajreddy.glidepad) before reporting.

## Reporting a vulnerability

Please **don't** open a public issue for security problems. Instead, either:

- use GitHub's [private vulnerability reporting](https://github.com/Neerajreddyapi/GlidePad/security/advisories/new), or
- email **pingdrop.support@gmail.com** with "Glide Pad security" in the subject.

Please include what the problem is, how to reproduce it, and which phone and Android version you used. You'll get a reply within 7 days. Once a fix is released, you'll be credited in the release notes if you'd like.

## Scope

Glide Pad acts as a Bluetooth keyboard and mouse and has no internet access. Issues that are especially relevant:

- Keystrokes or input reaching a device other than the one the user connected to.
- The app staying connected, or connecting, without the user's action.
- Anything that makes the app collect or leak user data.
